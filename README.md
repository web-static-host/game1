# Вертикаль

2D-симулятор колонии в разрезе бесконечного мира. Копайте вниз через настоящие геологические слои к магме и стройтесь вверх до космоса. Платформа: Android (RuStore), движок Godot 4.4.

Подробности в дизайн-документе [`docs/GDD.md`](docs/GDD.md).

## Что уже есть

- Бесконечный процедурный мир во все стороны.
- Реалистичные слои: почва → осадочные породы (уголь, вода, соль, нефть, метан, пещеры) → гранит с рудными жилами и кимберлитовыми трубками → базальт и магма → мантия.
- Туман войны: содержимое клетки видно только после раскопки соседней.
- **Жители:** 5 человек обоих полов. Ходят по поверхности, тоннелям и лестницам, сами разбирают работу, прокачивают навыки копки, стройки и сбора.
- **Стройки:** тоннель или комната выбранного размера. Этап 1 — копка (с сообщениями о находках), этап 2 — строительство за дерево и камень. Любую стройку можно поставить на паузу или отменить.
- **Ресурсы поверхности:** деревья (дерево), валуны (камень), кусты с ягодами (еда). На старте склад пуст.
- **Жизнь колонии:** сон (кровати), еда (ягоды, фермы, столовая), настроение, профессии, пары и дети (рождаются, только если есть свободные кровати), взросление.
- **Комнаты:** стены из дерева, глины или камня (по мере добычи); после постройки — назначение: жилая, склад, ферма, столовая (обустройство за ресурсы).
- **Тоннели:** чем шире, тем больше пропускная способность — в узком жители толкаются.
- **Хранение:** без складов ресурсы лежат кучами у базы (до 50 каждого); склады увеличивают вместимость, в складе можно выбрать, что хранить. Песок, грунт и гравий — пустая порода, уходят в отвал без лимита.
- **Правила стройки:** тоннели только под землёй; деревья, кусты и валуны на месте стройки убираются на этапе копки (как ресурс); второй этаж — только если в нижнем здании построена лестница; комната всегда стоит на опоре.
- **Нагрузки:** каждая комната весит (дерево 0,6 т, глина 1,5 т, камень 2,2 т на клетку) и давит на нижние; стены держат на метр ширины: дерево 2,5 т, глина 10 т, камень 28 т (ветхие — меньше). На каменное основание можно поставить несколько лёгких деревянных этажей. Перегруженная комната трещит (предупреждение) и через минуту рушится. Наземная башня не может быть выше основания больше чем в 3 (дерево), 4 (глина), 6 (камень) раз — иначе её опрокинет ветер.
- **Стихийные бедствия** (галочка при создании новой игры): очень редкие бури (раз в 4–10 часов игры) изнашивают наземные постройки; землетрясения (раз в 12–30 часов, чаще в глубоких колониях) — износ, рушится перегруженное, ослабевают своды. Перед толчками земля дрожит; без игрока бедствий нет.
- **Копка по срезам:** комнату и штрек копают по столбцу, шахту — по 2 ряда; каждый срез сразу крепят деревом, только потом копают следующий. Под идущей стройкой ничего не осыпается.
- **Разведка:** карта открывается по мере продвижения жителей, камеру нельзя увести за разведанное.
- **Физика:** сыпучие породы (песок, гравий, обломки) осыпаются в пустоты; у каждой породы свой пролёт без опор (глина ~3 м, песчаник 5, известняк 6, гранит 10, глубже — меньше) — шире нужна крепь (дерево); выработка без крепи, простоявшая больше 3 минут (пауза, нет материалов), обваливается; обвалы ранят жителей.
- **Природа:** деревья растут медленно (саженец → взрослое) и разрастаются только рядом с другими деревьями, на свободной траве; кусты не исчезают при сборе — ягоды отрастают, новые кусты появляются редко; голодный житель при пустом складе сам идёт есть ягоды с куста.
- **Водоёмы:** озёра от луж до огромных; по воде не пройти — нужен мостик; рыба (её не видно) ловится с берега (медленно), с мостика (быстрее) или с пристани (быстрее всего), запас рыбы восстанавливается.
- **Добыча на месте:** срубленное дерево, камень из валуна, ягоды, рыба, порода и руда из выработки ложатся там, где добыты; свободные жители относят их на склад, а носильщики строек берут прямо из кучи. Пустая порода (грунт, песок, гравий) сразу уходит в отвал.
- **Управление без режимов:** нажатие само показывает то, что под пальцем (житель, стройка, дерево, клетка) с нужными кнопками; «Стройка» — разовый режим, после «Построить» или «Отмены» всё возвращается.
- **Комнаты** — 3 м в высоту, три размера на выбор.
- **Доставка материалов:** со склада ничего не списывается мгновенно — жители носят материалы на стройку по 5 штук. Над стройкой плашки «значок 3/10»: число растёт по мере доставки; красная плашка — ресурса нет нигде, носить неоткуда.
- **Работники склада:** в складе выбирается число работников и норма запаса для каждого ресурса. Работники сами находят деревья, валуны, кусты (и рыбу), добывают и относят на склад, пока запас ниже нормы. Выше нормы не добывают — склад не забивается.
- **Износ и ремонт:** постройки ветшают. Дерево на поверхности служит 20 лет, под землёй быстрее (сырость, жара); глина 40 лет, камень 100 лет — ему всё равно, где стоять. При 70 % и 90 % износа — предупреждения, кнопка «Ремонт» (нужна часть материалов). При 100 % постройка рушится: обломки, травмы, падают верхние этажи, может обвалиться порода. Пока игрока нет, ничего не рушится.
- **Стихии:** вода и лава текут: вскрыли подземное озеро или копнули под озером — выработки затапливает. Лава вне очага остывает базальтом, с водой даёт камень и пар, сжигает постройки. Вскрытый водоносный пласт сочится. Метан из газовых карманов расходится по выработкам и поднимается вверх, взрывается от искр кирки, душит. Жара от глубины и лавы ранит жителей. Против всего этого — новые назначения комнат: **насосная** (откачивает воду в радиусе 16 м) и **вентиляция** (выводит газ и охлаждает в радиусе 20 м). Под водой жители всплывают к ближайшему месту, где можно дышать; по мелководью ходят вброд.
- **Геолог:** почуяв воду, магму или газ рядом с забоем, бригада останавливается и ждёт решения: «Продолжить» — копать на свой риск.
- **Экономика:** наука — учёные в **лаборатории** копят очки и открывают технологии (кнопка «Наука»): обжиг кирпича → **печь** (2 глины + 1 дерево → 2 кирпича) и кирпичные стены; электричество → **генератор** (жжёт уголь или дрова), с энергией насосы, вентиляция и лаборатория работают сильнее; металлургия → **кузница** (2 железа + 1 уголь → 1 сталь) и стальные конструкции (лёгкие, очень прочные); гидропоника — фермы с энергией дают больше; бурение — копка в полтора раза быстрее. Новая профессия — «Учёный». Энергия видна в верхней строке (даёт/нужно).
- **Сутки:** игровые сутки — 3 минуты; с 22:00 до 6:00 ночь (темнеет небо), жители ложатся спать, едят 2–3 раза в день. Голодные ходят и работают медленнее, без еды здоровье тает — примерно через двое суток житель умирает (сначала приходит предупреждение; без игрока никто не умирает). Падение с высоты больше 4 м травмирует.
- **Метан — топливо:** вскрытые газовые карманы и угольные пласты долго сочатся метаном. Комната «Дегазация» собирает его в ресурс «Метан», генератор жжёт его в первую очередь. Вентиляция только охлаждает.
- **Календарь:** игровые сутки — 3 минуты, год — 18 часов игры. Дата и время — в правом верхнем углу.
- **Снос:** готовую постройку можно снести — возвращается половина материалов; при надстройке лестница в нижнем здании добавляется автоматически.
- **Семьи:** 1 кровать = 1 житель; ребёнок рождается, если есть свободная кровать, еда и сытая мама; дети растут (малыш → подросток → взрослый) и едят вдвое больше.
- Температура, давление и кислород по реальным формулам, от магмы до космоса.
- Сохранение и оффлайн-прогресс (жители работают до 3 часов, пока игра закрыта).

## Управление

| Действие | Как |
|---|---|
| Двигать карту | один палец (при стройке — двумя) |
| Масштаб | два пальца (щипок), на ПК колесо мыши |
| Заложить комнату | «Стройка» → «Комната» → наверху выбрать размер (3×3, 6×3, 9×3) и материал → коснуться карты (комната сама прилипает к земле или этажу) → «Построить» |
| Заложить тоннель / мост | «Стройка» → «Тоннель» или «Мост» → провести пальцем рамку → «Построить» |
| Отправить жителя | нажать на жителя → «Отправить» → нажать точку на карте (так разведывается карта) |
| Сохранить, новая игра | «Меню» |
| Пауза / отмена стройки | нажать на стройку |
| Срубить дерево, разбить валун, собрать ягоды | нажать на объект → «Срубить» (или «…все рядом») |
| Мостик / пристань | «Стройка» → «Мост», провести пальцем над озером (ряд сам привяжется к воде) |
| Узнать о жителе или клетке | нажать на него |
| Профессия жителя | житель → «Профессия: < >» |
| Назначение комнаты | готовая комната → выбрать → «Обустроить» |
| Работники склада и нормы запаса | склад → «Работников склада», «Держать в запасе» |
| Ремонт | постройка → «Ремонт» (полоска «Износ» показывает, сколько осталось) |
| Исследования | «Наука» → «Изучать» (нужна лаборатория с учёными) |
| Новая игра, стихийные бедствия | «Меню» → «Новая игра» → галочка «Стихийные бедствия» → «Начать» |
| Ускорить время (для тестов) | кнопка «×1 / ×10 / ×100» |

## Разработка

Нужен [Godot 4.4.1](https://godotengine.org/download/archive/4.4.1-stable/).

```bash
# открыть в редакторе
godot -e --path .

# автотесты
godot --headless --path . --import
godot --headless --path . -s res://tests/run_tests.gd

# карта геологии (1 пиксель = 1 м) для настройки генератора
godot --headless --path . -s res://tests/render_map.gd -- map.png -300 -60 600 500 <seed>
```

### Сборка APK

При каждом push GitHub Actions (`.github/workflows/build.yml`) запускает тесты и собирает отладочный APK. Последний APK скачивается напрямую: https://github.com/web-static-host/game1/releases/latest/download/vertikal.apk (все сборки — в разделе Releases). Для публикации в RuStore понадобится release-ключ: настроим перед релизом.

### Структура

```
scripts/world/   генерация, данные мира, материалы, среда, отрисовка
scripts/game/    раскопки, сохранения, форматирование
scripts/ui/      камера и сенсорное управление, интерфейс
scripts/main.gd  сборка сцены, оффлайн-прогресс, автосохранение
shaders/         небо (цвет по высоте, звёзды в космосе)
tests/           автотесты и инструменты
```
