# Вертикаль

2D-симулятор колонии в разрезе бесконечного мира. Копайте вниз через настоящие геологические слои к магме и стройтесь вверх до космоса. Платформа: Android (RuStore), движок Godot 4.4.

Подробности в дизайн-документе [`docs/GDD.md`](docs/GDD.md).

## Что уже есть

- Бесконечный процедурный мир во все стороны.
- Реалистичные слои: почва → осадочные породы (уголь, вода, соль, нефть, метан, пещеры) → гранит с рудными жилами и кимберлитовыми трубками → базальт и магма → мантия.
- Туман войны: содержимое клетки видно только после раскопки соседней.
- **Жители:** 5 человек обоих полов. Ходят по поверхности, тоннелям и лестницам, сами разбирают работу, прокачивают навыки копки, стройки и сбора.
- **Стройки:** тоннель или комната выбранного размера. Этап 1 — копка (с сообщениями о находках), этап 2 — строительство за дерево и камень. Любую стройку можно поставить на паузу или отменить.
- **Ресурсы поверхности:** деревья (дерево), валуны (камень), кусты с ягодами (еда). На старте склад пуст.
- **Жизнь колонии:** сон (кровати), еда (ягоды, фермы, столовая), настроение, профессии, пары и дети (рождаются, только если есть свободные кровати), взросление.
- **Комнаты:** стены из дерева, глины или камня (по мере добычи); после постройки — назначение: жилая, склад, ферма, столовая (обустройство за ресурсы).
- **Тоннели:** чем шире, тем больше пропускная способность — в узком жители толкаются.
- **Хранение:** без складов ресурсы лежат кучами у базы (до 50 каждого); склады увеличивают вместимость, в складе можно выбрать, что хранить. Песок, грунт и гравий — пустая порода, уходят в отвал без лимита.
- **Правила стройки:** тоннели только под землёй; деревья, кусты и валуны на месте стройки убираются на этапе копки (как ресурс); второй этаж — только если в нижнем здании построена лестница; комната всегда стоит на опоре.
- **Семьи:** 1 кровать = 1 житель; ребёнок рождается, если есть свободная кровать, еда и сытая мама; дети растут (малыш → подросток → взрослый) и едят вдвое больше.
- Температура, давление и кислород по реальным формулам, от магмы до космоса.
- Сохранение и оффлайн-прогресс (жители работают до 3 часов, пока игра закрыта).

## Управление

| Действие | Как |
|---|---|
| Двигать карту | один палец (режимы «Осмотр» и «Сбор») или два пальца |
| Масштаб | два пальца (щипок), на ПК колесо мыши |
| Заложить тоннель / комнату | режим «Тоннель» или «Комната», провести пальцем рамку, нажать «Построить» |
| Пауза / отмена стройки | «Осмотр» → нажать на стройку |
| Срубить дерево, разбить валун | режим «Сбор», нажать на объект |
| Узнать о жителе или клетке | «Осмотр» → нажать |
| Профессия жителя | «Осмотр» → житель → «Профессия: < >» |
| Назначение комнаты | «Осмотр» → готовая комната → выбрать → «Обустроить» |
| Ускорить время (для тестов) | кнопка «×1 / ×10 / ×100» |

## Разработка

Нужен [Godot 4.4.1](https://godotengine.org/download/archive/4.4.1-stable/).

```bash
# открыть в редакторе
godot -e --path .

# автотесты
godot --headless --path . --import
godot --headless --path . -s res://tests/run_tests.gd

# карта геологии (1 пиксель = 1 м) для настройки генератора
godot --headless --path . -s res://tests/render_map.gd -- map.png -300 -60 600 500 <seed>
```

### Сборка APK

При каждом push GitHub Actions (`.github/workflows/build.yml`) запускает тесты и собирает отладочный APK. Последний APK скачивается напрямую: https://github.com/web-static-host/game1/releases/latest/download/vertikal.apk (все сборки — в разделе Releases). Для публикации в RuStore понадобится release-ключ: настроим перед релизом.

### Структура

```
scripts/world/   генерация, данные мира, материалы, среда, отрисовка
scripts/game/    раскопки, сохранения, форматирование
scripts/ui/      камера и сенсорное управление, интерфейс
scripts/main.gd  сборка сцены, оффлайн-прогресс, автосохранение
shaders/         небо (цвет по высоте, звёзды в космосе)
tests/           автотесты и инструменты
```
