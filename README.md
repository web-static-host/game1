# Вертикаль

2D-симулятор колонии в разрезе бесконечного мира. Копайте вниз через настоящие геологические слои к магме и стройтесь вверх до космоса. Платформа: Android (RuStore), движок Godot 4.4.

Подробности в дизайн-документе [`docs/GDD.md`](docs/GDD.md).

## Что уже есть (этап M1)

- Бесконечный процедурный мир во все стороны.
- Реалистичные слои: почва → осадочные породы (уголь, вода, соль, нефть, метан, пещеры) → гранит с рудными жилами и кимберлитовыми трубками → базальт и магма → мантия.
- Туман войны: содержимое клетки видно только после раскопки соседней.
- Раскопки: бригады копают по очереди, твёрдость породы и жара замедляют работу.
- Температура, давление и кислород по реальным формулам, от магмы до космоса.
- Сохранение и оффлайн-прогресс (до 8 часов).

## Управление

| Действие | Как |
|---|---|
| Двигать карту | один палец (режим «Осмотр») или два пальца |
| Масштаб | два пальца (щипок), на ПК колесо мыши |
| Узнать, что в клетке | режим «Осмотр», нажать на клетку |
| Заказать раскопки | режим «Копать», провести пальцем по клеткам |
| Отменить заказ | режим «Копать», провести, начав с уже заказанной клетки |
| Ускорить время (для тестов) | кнопка «×1 / ×10 / ×100» |

## Разработка

Нужен [Godot 4.4.1](https://godotengine.org/download/archive/4.4.1-stable/).

```bash
# открыть в редакторе
godot -e --path .

# автотесты
godot --headless --path . --import
godot --headless --path . -s res://tests/run_tests.gd

# карта геологии (1 пиксель = 1 м) для настройки генератора
godot --headless --path . -s res://tests/render_map.gd -- map.png -300 -60 600 500 <seed>
```

### Сборка APK

При каждом push GitHub Actions (`.github/workflows/build.yml`) запускает тесты и собирает отладочный APK. Скачать его можно на вкладке Actions → нужный запуск → Artifacts → `vertikal-debug-apk`. Для публикации в RuStore понадобится release-ключ: настроим перед релизом.

### Структура

```
scripts/world/   генерация, данные мира, материалы, среда, отрисовка
scripts/game/    раскопки, сохранения, форматирование
scripts/ui/      камера и сенсорное управление, интерфейс
scripts/main.gd  сборка сцены, оффлайн-прогресс, автосохранение
shaders/         небо (цвет по высоте, звёзды в космосе)
tests/           автотесты и инструменты
```
