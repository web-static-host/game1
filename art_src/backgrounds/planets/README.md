# Фоны планет — прототипы

Картинки ChatGPT (1536×1024, без прозрачности) — как должен выглядеть фон на каждой
планете. Это образец, не слои: в игре фон собирается из прозрачных слоёв с параллаксом
(см. `../README.md`). Пока на планетах — земные слои, подкрашенные оттенком `sky`
из `scripts/game/planet.gd`.

| Файл | Планета | Что на картинке |
|---|---|---|
| mercury.png | Меркурий | тёмно-синее звёздное небо, серые холмы в кратерах |
| venus.png | Венера | оранжевое дымное небо, вулканы, лава |
| mars.png | Марс | розовое небо, красные столовые горы, валуны |
| jupiter.png | Юпитер | полосатое оранжевое небо, море облаков |
| saturn.png | Сатурн | голубое небо, бледно-жёлтые холмы, ледяные кристаллы |
| uranus.png | Уран | бирюзовое небо, ледяные горы |
| neptune.png | Нептун | синее штормовое небо с вихрем, синие ледяные горы |
