# Фоны планет — прототипы

Картинки ChatGPT (1536×1024, без прозрачности) — как должен выглядеть фон на каждой
планете. Это образец, не слои: в игре фон собирается из прозрачных слоёв с параллаксом
(см. `../README.md`). Пока на планетах — земные слои, подкрашенные оттенком `sky`
из `scripts/game/planet.gd`.

## Слои в игре
ChatGPT присылает лист со всеми слоями планеты (`<планета>/sheet.png`: небо, облака, горы,
холмы, ближний край; вместо прозрачности — нарисованная шахматка). Рамки слоёв на листе —
в `prepare_planet.py` (SHEETS). Запуск:

    python3 art_src/backgrounds/planets/prepare_planet.py neptune

→ `assets/background/<планета>/`: sky, mountains, hills, near, clouds. Если у планеты есть
`sky.png`, игра (`main.gd`, `_apply_planet_sky`) берёт её слои вместо земных: горы — в слот
гор (параллакс 0.15), холмы — в слот леса (0.3), ближний край — в слот холмов (0.45), небо —
картинкой у горизонта. Размеры кусков в клетках — `PLANET_LAYERS` в `main.gd`.
Снимки: `tests/planet_sky_preview.gd -- <папка> <планета>`.
