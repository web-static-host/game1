# Логотип «Гаврики» — промты для ChatGPT

Супер-Гаврик: тот же житель-треугольник с одним глазом, что на прототипе
(`art_src/characters/prototype_chatgpt.png`), но бирюзовый — градиент от #2CD6C1 (верх) к #0993B3 (низ),
как `CreatureArt.SUPER_A / SUPER_B`. Для лого — без свечения и ауры.

## 1. Логотип (главный экран, страница в магазине)
```
Нарисуй логотип мобильной игры «Гаврики» — милая подземная колония монстриков, которые копают вглубь и строят комнаты.
Персонаж — Супер-Гаврик: в точности такой же монстрик, как на приложенной картинке (одноглазый, тело-трапеция с широкой головой, длинные руки дугой с четырьмя пальцами, короткие ножки с круглыми ступнями, румяные щёки, улыбка с одним зубом), но бирюзового цвета — плавный градиент от #2CD6C1 сверху к #0993B3 снизу. БЕЗ свечения, ореола, искр и сияния вокруг.
Композиция: Супер-Гаврик стоит по центру сверху, гордо держит над головой кирку, будто только что прокопался наверх; под ним — крупная надпись «ГАВРИКИ»: толстые округлые мультяшные буквы, будто вырезанные из земли/камня, тёплые песочно-коричневые с объёмом и светлой кромкой сверху; на буквах — пара травинок и камешков. Сзади надписи — край земли в разрезе со слоями почвы и маленьким входом в норку.
Стиль: как на картинке — мультяшный 3D, мягкий объём, сочные тёплые цвета, свет сверху-слева. Без других персонажей, без лишнего текста.
Формат: 1536×1024, прозрачный фон (PNG), логотип по центру с отступами.
```

## 2. Иконка приложения
```
Сделай иконку приложения для этой же игры: квадрат 1024×1024, углы не скругляй (скруглит телефон).
В центре — голова и плечи того же Супер-Гаврика крупно (бирюзовый градиент #2CD6C1 → #0993B3, без свечения), он высовывается из ямки в земле и подмигивает, в руке — кирка на плече. Фон — разрез земли тёплых песочно-коричневых тонов со слоями и парой блестящих камешков. Без надписей. Персонаж занимает ~70% иконки, хорошо читается даже в размере 48 px.
```
