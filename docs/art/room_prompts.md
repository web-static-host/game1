# Промты ChatGPT для комнат
Как пользоваться:
1. Для каждого промта приложи 2 картинки: **основу нужного размера** из `docs/art/room_bases/`
   (`wood_3.png`, `wood_6.png` или `wood_9.png`) и **прототип** `docs/art/prototype_chatgpt.webp`.
2. Вставь промт целиком. Лучше один чат на одну комнату — три размера подряд, тогда стиль совпадёт.
3. Готовые картинки клади в корень `art_src/`, имя — `<комната>_<размер>.png`
   (например `home_6.png`); для дополнительных вариантов — `storage_6_empty.png`, `hearth_9_brick.png` и т. п.
   Можно и как попало — разберу.

Что дальше с ними: картинка комнаты — образец расстановки, а предметы беру из листа предметов
(второй шаг, см. ниже) — вырезаю и расставляю по логике игры. Мебель в игре — отдельными
спрайтами поверх комнаты, поэтому подходит к любому материалу стен.

Комната «Без назначения» — это пустая коробка, для неё ничего не нужно.

## Листы предметов (второй шаг)

После картинки комнаты — в том же чате попроси лист предметов. Важно: строго спереди, без вида
сверху — иначе предметы не стыкуются с комнатой (у неё пол виден ребром). Из него предметы вырезаются
без потерь (с картинки комнаты деревянная мебель не отделяется от деревянной стены), а сама
картинка комнаты остаётся образцом расстановки. Имя файла — `<комната>_items.png`.
Для остальных комнат — по тому же образцу: «Предметы:» — всё, что есть в трёх
картинках этой комнаты.
